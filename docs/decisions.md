## 알려진 미해결

- 종단 응답 시간 정식 측정 없음(리뉴얼 후에도 p95·동시 부하 미측정). TTS 단독 5.21초(로컬 RTX 5070).
- 리뉴얼 후 실제 사람이 마이크로 끝까지 돌려 본 기록 없음(가짜 마이크로 VAD 감지·업로드까지만 확인).
- 미리 만든 음성 중 끝 잘림 의심 204개(생성 쪽 검증 보고서 기준)를 사람이 들어 보지 않음.
- 요리명 LLM(EXAONE) 제거의 인식 정확도 영향(A/B) 미측정.
- 레시피 등록 음성 생성 소요 시간(화면 안내 "보통 1~3분")은 추정, 미측정.
- 학습 스크립트는 Colab·개인 작업 공간에만 있음.
- STT 원본 모델 zero-shot 기준선 미측정(기준선은 2 epoch 시점).
- 모델 저장소 private.
