# 셰프이어(ChefEar) — 경쟁사 앱 직접 사용 결과

말씀하신 대로 경쟁사 앱 3개(레시피오, 레시핏, 만개의레시피)를 팀원별로 직접 설치해 사용해본 뒤 페인포인트·차별점을 다시 점검했습니다. 제출 전 각 앱의 실제 기능을 앱스토어 공식 정보로 한 번 더 교차 검증했습니다.

## 1. 레시피오(홍민하) — 텍스트 챗봇형

- 재료 대체 질의("믹서기에 갈지 않고 통째로 넣고 싶은데")에 대안 검색 없이 "레시피에 없는 조리법이라 안내할 수 없다"며 즉시 거절
- 레시피 저장은 단순 북마크만 가능, 사용자가 수정한 버전을 따로 저장하는 기능 없음
- 쿠팡 연동 구매, 광고 배너 노출 — 커머스/광고 중심 수익 모델

## 2. 레시핏(하주성) — 음성 핸즈프리형

유튜브 영상·숏츠·텍스트를 단계별 인앱 레시피로 변환해, 음성 인식 기반 타이머·읽어주기·다음 단계 이동까지 지원하는 핸즈프리 요리 도우미입니다. 저희 서비스와 마찬가지로 "화면을 보지 않고 진행"이라는 컨셉은 동일하나, 핵심 차이는 **데이터 신뢰성**에 있습니다 — 레시핏은 사용자가 붙여넣은 유튜브 영상을 AI가 그때그때 변환하는 방식이라 레시피 품질·일관성이 검증되지 않는 반면, 저희는 조회수 1위 기준으로 자동 선정된 표준레시피(60,282건, 실측 대표성 23% 확인)를 사용합니다. 또한 레시핏은 "다음", "타이머 n분"처럼 정해진 명령어 방식으로 보이며, 진행 중 재료가 바뀌는 상황에 대한 대응 기능은 확인되지 않았습니다.

## 3. 만개의레시피(김승욱)

- 주 타겟이 기존 주부층이라 저희 페르소나(자취 초보)와 다소 어긋남
- 레시피 등록 기능은 존재하나 **iOS 앱에서는 등록이 불가능**하고 안드로이드 앱·PC 웹에서만 가능합니다. iOS 사용자 기준으로는 스크랩(찜)만 가능한 것이 맞습니다.
- 음성 인식 기능이 있으나, 이는 **레시피를 읽어주거나 진행을 안내하는 용도가 아니라 새 레시피를 등록(작성)할 때 음성으로 받아쓰는 용도**입니다. 조리 중 손이 바쁜 상황에서 활용할 수 있는 음성 기능은 아닙니다.
- 텍스트 중심 UI라 기능이 많고 다소 복잡하지만, 이미지와 정확한 정량 표기는 잘 되어 있음

## 종합 — 페인포인트와 차별점 매핑

**2026-08-28 갱신**: 아래 표의 "ChefEar 차별화" 열은 최초 작성 시점(재료 대체·계정 기반 개인화 저장이 아직 Must였던 v0.8 초안) 기준이었다. 2026-08-27 팀 결정으로 두 기능이 전면 제거되고 대신 "로그인 없는 등록 + 관리자 승인"으로 방향이 바뀌어(`docs/specs/remove_ingredient_substitution.md`, `docs/specs/remove_user_accounts.md`), 아래 표를 현재 기준으로 다시 썼다. 원본 앱 사용기(위 1~3절)는 그대로 유효한 관찰이라 손대지 않았다.

| 경쟁앱 | 확인된 한계 | ChefEar 차별화 |
| --- | --- | --- |
| 레시피오 | 재료 대체 실패 시 대안 검색 없이 즉시 거절, 저장은 단순 북마크, 사용자가 수정한 버전을 따로 저장 불가 | 조회수 1위 기준 검증된 표준레시피 자동선정(60,282건, 23% 대표성 실측). 사용자가 새 레시피를 등록할 수 있다는 점은 같지만, ChefEar는 로그인 없이도 등록 가능하고 관리자 승인을 거쳐야 노출되어 저품질 등록이 그대로 섞이지 않음 |
| 레시핏 | 유튜브 기반 변환이라 레시피 품질·일관성 미검증, 정해진 명령어 방식 | 조회수 1위 기준 검증된 표준레시피(60,282건, 23% 대표성 실측) + 자유발화 기반 임베딩 의도분류(정해진 명령어 불필요) |
| 만개의레시피 | 음성은 레시피 작성(입력)용일 뿐 안내(출력)용이 아님, iOS에선 레시피 등록도 불가, 등록 검증 절차 불명 | 조리 진행 전체가 음성 안내(출력) 기반, 등록도 로그인·플랫폼 무관하게 발화만으로 가능. 검증 절차가 불명한 만개의레시피와 달리, ChefEar는 신규 등록마다 관리자 승인(Y/N) 관문을 명시적으로 둠 |

세 앱 모두 손이 바쁜 상태에서도 화면 없이 진행을 안내받는다는 저희 핵심 페인포인트를 온전히 풀지 못하고 있음을 직접 확인했습니다. 특히 레시핏처럼 음성 기반 경쟁자가 이미 존재한다는 점에서, 저희 차별점을 '음성 지원 여부' 자체가 아니라 **AI(임베딩 유사도 기반 의도분류)로 정해진 명령어 없이 자유롭게 말해도 이해하는 것 + 검증된 표준 데이터 + 계정 없이도 열려있는 등록에 관리자 승인이라는 품질 관문을 두는 것**의 조합에 있다고 재정리했습니다. (재료 대체와 계정 기반 개인화 저장은 이후 실사용 리포트를 바탕으로 팀이 범위에서 제외했습니다.)
