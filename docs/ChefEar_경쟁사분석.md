# 셰프이어(ChefEar) — 경쟁사 앱 직접 사용 결과

경쟁사 앱 3개(레시피오, 레시핏, 만개의레시피)를 팀원별로 직접 설치해 사용한 뒤 페인포인트·차별점을 점검했다. 앱스토어 공식 정보로 교차 검증했다. 사용기(1~3절)는 08-14 시점 기록이고, 4절 차별화 표는 2026-09-10 최종 기능 기준으로 다시 썼다.

## 1. 레시피오(홍민하) — 텍스트 챗봇형

- 재료 대체 질의("믹서기에 갈지 않고 통째로 넣고 싶은데")에 대안 검색 없이 "안내할 수 없다"며 즉시 거절
- 저장은 단순 북마크만 가능, 수정 버전 저장 없음
- 쿠팡 연동 구매, 광고 배너 — 커머스 중심

## 2. 레시핏(김승욱) — 음성 핸즈프리형

유튜브 영상·숏츠·텍스트를 단계별 레시피로 변환해 음성 타이머·읽어주기·다음 단계 이동을 지원한다. "화면을 보지 않고 진행"이라는 컨셉은 같지만, 사용자가 붙여넣은 영상을 AI가 그때그때 변환하므로 품질·일관성이 검증되지 않고, "다음", "타이머 n분"처럼 정해진 명령어 방식이다.

## 3. 만개의레시피(김승욱)

- 주 타겟이 주부층이라 자취 초보 페르소나와 어긋남
- iOS 앱에서는 레시피 등록 불가(스크랩만), 안드로이드·PC 웹에서만 가능
- 음성 기능은 레시피 작성(입력)용이지 조리 안내(출력)용이 아님
- 이미지와 정량 표기는 정확하지만 텍스트 중심 UI라 복잡

## 4. 페인포인트와 차별점

| 경쟁앱 | 확인된 한계 | ChefEar |
| --- | --- | --- |
| 레시피오 | 화면을 봐야 하는 텍스트 채팅, 수정 버전 저장 불가 | 음성 출력 중심. 로그인 사용자는 본인 레시피를 등록·수정·삭제 |
| 레시핏 | 유튜브 변환이라 품질 미검증, 정해진 명령어 | 검수 가능한 500개 큐레이션 데이터 + 임베딩 의도분류로 자유발화 이해 |
| 만개의레시피 | 음성은 입력용, iOS 등록 불가, 검증 절차 불명 | 조리 진행 전체가 음성 안내, 플랫폼 무관 등록, 조리 용어를 설명과 함께 읽어줌 |

세 앱 모두 손이 바쁜 상태에서 화면 없이 진행을 안내받는다는 핵심 페인포인트를 온전히 풀지 못한다. 레시핏처럼 음성 경쟁자가 있으므로 ChefEar의 차별점은 음성 지원 여부가 아니라 **자유발화 이해 + 검수 가능한 데이터 + 초보자를 위한 용어 설명**의 조합에 둔다. 재료 대체는 08-27에, 6만 건 규모의 데이터 커버리지는 09-01에 각각 범위에서 뺐다(`docs/decisions.md`).
