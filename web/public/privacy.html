셰프이어(ChefEar) 개인정보처리방침

시행일: 2026-10-20

셰프이어는 음성으로 레시피를 한 단계씩 안내하는 비상업 포트폴리오 서비스입니다(AI Human 7기 1차 팀 프로젝트). 서비스를 쓰는 데 필요한 최소한의 정보만 다룹니다.

1. 처리하는 정보

정보언제용도보관
이메일 주소, 계정 식별자(구글 로그인 시 이름·프로필 사진 포함)로그인할 때로그인, 본인 레시피 구분계정 삭제 요청 시까지
말소리(한 문장 분량)마이크를 켜고 말할 때음성을 글자로 바꾸기(음성 인식)저장하지 않음. 변환 직후 버림
대화 진행 상태(화면, 진행 중인 레시피, 최근 대화 글자)서비스를 쓰는 동안대화 이어가기세션 기록으로 보관, 요청 시 삭제
직접 등록한 레시피와 그 합성 음성레시피를 등록할 때본인에게만 보여 주고 읽어 주기직접 삭제하거나 계정 삭제 요청 시까지

광고, 추적, 판매 목적으로 쓰지 않으며 제3자에게 팔거나 넘기지 않습니다. 외부 LLM(생성형 AI) API로 보내지 않습니다.

2. 처리를 맡기는 곳

  • Supabase — 로그인, 데이터베이스, 파일 저장
  • Modal — 음성 인식·음성 합성 서버(요청을 처리하는 동안만 사용)
  • Vercel — 웹 화면 제공
  • Google — 구글 로그인을 고른 경우 계정 확인
