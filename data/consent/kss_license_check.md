# KSS 라이선스 확인 기록

## 결론

KSS(Korean Single Speaker Speech Dataset)는 CC BY-NC-SA 4.0(저작자표시-비영리-동일조건변경허락)
라이선스로 배포되며, 본 프로젝트는 수업 과제로 진행되는 비상업적 프로젝트이므로 라이선스 조건을
충족한다. 팀원 본인 목소리를 녹음/사용하지 않으므로 별도의 팀원 동의서는 필요 없다.

## 확인 내용

- 데이터셋: KSS — 전문 성우 1인이 낭독한 한국어 음성, 총 12,854건(음성 파일 + 대본 쌍,
  `data/kss/metadata.csv` 기준)
- 라이선스: CC BY-NC-SA 4.0 — 비상업적 이용만 허용, 동일 조건 변경허락, 저작자 표시 필요
- 상업적 이용 여부: 없음 — 서비스 배포도 학습 과제 범위(팀 GPU 서버, 비상업)
- 사용 목적: TTS(Qwen3-TTS) 파인튜닝 원본 음성 + STT 파인튜닝용 학습데이터(KSS 원문 음성 +
  파인튜닝된 TTS가 만든 합성 음성)
- 팀원 동의서 필요 여부: 불필요 — 팀원 본인 목소리를 녹음/사용하지 않음

## 실물 데이터 확보 현황

- 전체 12,854개 중 412개는 `data/kss/wavs/`에 로컬 스테이징(git-ignored)
- 나머지 포함 전체 12,854개는 팀장(김승욱)이 개인적으로 확보 완료, HF Hub `kimseunguk/recipe-kss-vits`에도
  업로드해둔 상태 — 팀 공유(드라이브 등)는 아직 진행 전
